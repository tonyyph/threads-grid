# Clean founder thread

**For:** founders, SaaS, indie hackers, build-in-public, developers, consultants, personal brands.
**Feeling:** a sharp, well-edited thought. Looks like it was written, not designed.

## Palette
- Paper #fafaf7 background, ink #0a0a0a text, muted #737373.
- Exactly one accent (orange #ff5a1f, electric blue #2b59ff or brand color) used for ≤ 2 things per post: a number, an underline, a pager.
- Dark variant: #0a0a0a background, #f5f5f5 text, same single accent.

## Type
- `inter` everywhere (or `space-grotesk` headings for a techier feel). Headlines 700–800, tracking −0.02 to −0.03em, line-height 1.0–1.1.
- Hook (post 1): 11–14% of post width. Other headlines: 6.5–8%. Body: 3.3–3.8%.
- Pager `01 / 06` top-left, brand/handle top-right, both 2.4% size, muted.

## Composition
- Text-forward, left-aligned, strong top-to-bottom hierarchy: label → headline → 1–3 lines of body.
- Signature move: hook headline crossing post 1→2 in giant type, plus one hairline `line` across all posts at ~84% height.
- Optional: a screenshot in a `browser` or `phone` frame on the proof post, slightly rotated (−3°) and crossing a seam.
- Use code/monospace (`jetbrains`) only for actual code or metrics.

## Avoid
Gradients, stock photos, emoji bullets, more than one accent, centered paragraphs, "motivational poster" layouts.

## Recommended setup
`style: clean-founder-thread` · template `connected-headline` or `educational` · 5–8 square or portrait posts.
