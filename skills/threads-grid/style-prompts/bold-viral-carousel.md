# Bold viral carousel

**For:** high-impact Threads/Instagram posts — "5 mistakes…", hot takes, myths vs. facts, listicles.
**Feeling:** loud, fast, impossible to scroll past — but still disciplined.

## Palette
- Near-black #0b0b0b background, white text, ONE loud color (acid lime #d7ff3a, hot red #ff3b30, electric blue #3d5afe).
- Inverted posts allowed: one post (usually the key insight) flips to accent background + black text.

## Type
- `space-grotesk` or `inter` 800, tracking −0.03em, line-height 0.95–1.0.
- Hook: 13–20% of post width, 3–6 words, can cross seam 1→2.
- Giant outline-feel numbers: the template's big number uses `accent` at opacity 0.15–0.25 behind the headline.
- Body: max 2 short lines, 3.4%+.

## Composition
- Portrait 1080×1350 recommended (more screen = more impact).
- Each post: number → headline (the mistake) → one line (the fix).
- Signature move: radial accent glows alternating top/bottom across every seam (template `educational`) so swiping feels continuous.
- "Swipe →" cue on post 1; "Save this" CTA pill on the last.
- One idea per post. If it needs a paragraph, it's two posts.

## Avoid
Multiple bright colors, emoji walls, small text, centered long copy, drop shadows, decorative fonts.

## Recommended setup
`style: bold-viral-carousel` · template `educational` or `connected-headline` · 6–8 portrait posts.
